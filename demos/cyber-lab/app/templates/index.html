Cyber Lab

An intentionally vulnerable application for learning about SQL injection.

Login

A login form that answers only welcome or wrong password — like a real one. It never shows the rows it read, yet data still leaks: through the welcome name, through error messages, or one yes/no answer at a time.

Product search

A product search that shows a table of results. Because the result is a table, a UNION SELECT can add rows from any other table — users, credit cards — to the list.

Teaching aid. This application is deliberately insecure and runs only on your own machine. Never expose it to a network.
